## 🚀 The Honest Story

I'm not a software developer. I'm a Data Analyst.

But I had an idea every time I opened a new tab, I'd lose focus. YouTube, Instagram, random browsing. Sound familiar?

So I decided to build something about it. Not just talk about it. Actually build it.

With the help of **Claude AI** and **Antigravity**, I went from a rough idea to a fully working Chrome Extension. No coding bootcamp. No Stack Overflow rabbit holes. Just clear thinking + the right AI tools.

---

## 🔹 What FocusTab Does

| # | Feature | Description |
|---|---------|-------------|
| 1️⃣ | **Wallpaper & Clock** | Full-screen wallpaper with a live clock and personalized greeting |
| 2️⃣ | **Daily Focus Prompt** | Asks "What is your main focus today?" every morning, visible all day |
| 3️⃣ | **Task List** | Simple add, complete, and delete task tracking |
| 4️⃣ | **Focus Mode** | Blocks Instagram, YouTube, LinkedIn, Reddit & more - shows your focus message instead |
| 5️⃣ | **Settings Panel** | Change name, upload wallpaper, manage block list |
| 6️⃣ | **Daily Quote** | A new motivational quote every day, automatically |
| 7️⃣ | **Focus Streak** | Tracks how many days in a row you've set a focus |
| 8️⃣ | **Pomodoro Timer** | Built-in 25-min focus sessions + 5-min breaks |

## 📈 How I Built It - My Exact Process

### 💭 Step 1 - Idea
I wanted a distraction-free new tab that keeps me focused on what matters.

### 📝 Step 2 - PRD (Product Requirements Document)
I used **Claude AI** to write a detailed PRD, breaking the project into 7 phases. This became my blueprint every feature, every edge case, documented before writing a single line.

### 🛠️ Step 3 - Build
I used **Antigravity** (an AI coding tool) and fed it the PRD phase by phase. It generated all the code - I reviewed, tested, and debugged.

### 🚀 Step 4 - Ship
Loaded it as an unpacked Chrome extension. Fixed real errors. Made UI tweaks. Pushed to GitHub.
